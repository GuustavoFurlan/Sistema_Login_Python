# Sistema_Login_Python
Sistema de login e gerenciamento de conta desenvolvido em Python para prática de programação.


Um sistema de login simples desenvolvido em **Python**, criado com o objetivo de praticar conceitos fundamentais de programação, estruturas condicionais, loops, funções de entrada e gerenciamento de dados.

## 📌 Funcionalidades

* Cadastro de usuário
* Criação de senha
* Geração de saldo inicial aleatório
* Sistema de login
* Verificação de usuário e senha
* Visualização de perfil
* Consulta de saldo
* Alteração de senha
* Logout
* Encerramento do sistema

## 🛠️ Tecnologias utilizadas

* Python
* Biblioteca `random`

## 📚 Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos como:

* Variáveis
* `if`, `elif` e `else`
* Estruturas `while`
* Entrada de dados com `input()`
* Saída de dados com `print()`
* Operadores de comparação
* Variáveis booleanas
* Formatação de strings com `f-string`
* Geração de números aleatórios
* Controle de fluxo

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/sistema-login-python.git
```

### 2. Entre na pasta

```bash
cd sistema-login-python
```

### 3. Execute o programa

```bash
python main.py
```
